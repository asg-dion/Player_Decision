How It Works

Every strategy starts with the same stamina and faces the same situations. Run the simulation to see how each one performs.

Conservative Plays it safe. Saves stamina for later turns.
Aggressive Goes all in. Burns stamina fast for quick points.
Risk-Taking Chases the biggest reward, even at long odds.
Balanced Weighs cost against reward before every move.

Score = points earned. Success rate = percent of actions that landed. Stamina remaining shows what's left unused.
